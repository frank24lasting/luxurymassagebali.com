# Luxury Massage Bali

Website premium home massage untuk pelanggan di seluruh Bali. Dibangun dengan React, TypeScript, Vite, Supabase, dan Cloudinary.

## Menjalankan proyek

```bash
npm install
npm run dev
```

## Verifikasi

```bash
npm run lint
npm run build
```

## Konfigurasi

Salin konfigurasi layanan ke `.env.local`. Jangan commit kredensial Supabase, Cloudinary, VAPID, atau service role.

- Domain produksi: `https://luxurymassagebali.com`
- Dashboard admin: `/langitdewata`
- Repository: `https://github.com/frank24lasting/luxurymassagebali.com`
- Upload baru: `luxury-massage-bali/{services,hero,articles,media}`

URL aset Cloudinary lama tetap didukung sampai migrasi media selesai.
